🎮 GBA 网页模拟器

在浏览器中直接运行 Game Boy Advance 游戏
支持键盘 + 触控 / 手柄

键盘默认映射：
方向键 → 十字键  |  Z → A  |  X → B
Enter → Start  |  V → Select
Q → L  |  E → R
⚠️ 电脑：加载后先点一下游戏画面，键盘才生效
📱 iPad + 外接键盘：先点「启用外接键盘」，再点游戏画面，然后按键
触屏：使用屏幕上的虚拟手柄（若未显示，点游戏菜单里的手柄图标）
请选择一个 .gba 文件开始游戏
支持 .gba / .zip 格式
所有操作在本地完成，不会上传任何文件
基于 EmulatorJS (mGBA 核心) 构建
请只使用你合法拥有的游戏 ROM。本项目不提供任何游戏文件。
