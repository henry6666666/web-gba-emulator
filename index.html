🎮 GBA 网页模拟器

在浏览器中直接运行 Game Boy Advance 游戏
支持键盘 + 触控 / 手柄

键盘默认映射：
方向键 / WASD → 十字键  |  Z / A → A  |  X / S → B
Enter → Start  |  Shift → Select  |  Q / W → L / R
手机：自动显示触控按钮，也可连接手柄
请选择一个 .gba 文件开始游戏
支持 .gba / .zip 格式
所有操作在本地完成，不会上传任何文件
基于 EmulatorJS (mGBA 核心) 构建
请只使用你合法拥有的游戏 ROM。本项目不提供任何游戏文件。
