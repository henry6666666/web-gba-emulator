🎮 GBA 网页模拟器

在浏览器中直接运行 Game Boy Advance 游戏
支持键盘 + 触控 / 手柄

键盘默认映射（与 EmulatorJS 一致）：
方向键 → 十字键
Z → A  |  X → B
A → X  |  S → Y（GBA 一般不用）
Enter → Start  |  V → Select
Q → L  |  E → R
⚠️ 加载完成后请先用鼠标点一下游戏画面，键盘才会生效（浏览器需要焦点）
请选择一个 .gba 文件开始游戏
支持 .gba / .zip 格式
所有操作在本地完成，不会上传任何文件
基于 EmulatorJS (mGBA 核心) 构建
请只使用你合法拥有的游戏 ROM。本项目不提供任何游戏文件。
